# Customer Segmentation Using Unsupervised Learning

## Project Overview
This project applies unsupervised machine learning techniques to segment mall customers based on annual income and spending scores.

## Objectives
- Explore and preprocess customer data.
- Apply K-Means clustering.
- Determine the number of clusters using the Elbow Method and Silhouette Score.
- Visualize and interpret customer segments.
- Compare results with Hierarchical Clustering.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Jupyter Notebook

## Methodology
1. Data loading and exploratory data analysis.
2. Data cleaning and feature selection.
3. Feature standardization.
4. Evaluation of cluster numbers.
5. K-Means clustering and optional Hierarchical Clustering.
6. Visualization and cluster profiling.

## Dataset
Mall Customer Segmentation Dataset:
https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python

## Project Files
- `clustering_analysis.ipynb`: Analysis and code.
- `figures/`: Generated visualizations.
- `Clustering_Analysis_Report.pdf`: Project report.

## Results
The analysis examines customer segments based on income and spending patterns. Final cluster characteristics and evaluation metrics are documented in the notebook and report.
